# Compositor Windows 中文版

本版采用 IAmTheBlurr/CompositorWindows 的完整 Qt 界面、自绘图标与 Inter 字体。原作者 Robbie Tilton 与原 Windows 移植者的版权、许可和对应源码均保留。Inter 不包含汉字，中文字形由 Windows 的中文字体补齐；没有重新设计控件。

安装后从应用根目录 `CompositorStart.exe` 启动。默认界面为中文；启动参数 `-- --english` 使用参考英文显示。启动自动检查本 fork 的签名更新，帮助菜单可手动检查。新版本下载后先验证生产密钥签名、压缩包和每个文件的 SHA-256，再运行离线模型/图像编解码健康检查。失败保留旧版本；安装完成后按“保存并重启”，原编辑器会询问未保存的项目。拒绝保存或取消关闭可继续旧版，下一次启动进入已验证的新版本。

请将整个 `.comp` 项目文件夹保存到文档目录。不要把项目放在 `versions` 或 `state` 中。应用自动更新只写版本和状态目录，不修改外部项目。安装没有管理员要求；下载包没有 Authenticode 商业证书签名，应用内部更新使用独立的生产密钥验证。

Windows 移植当前跟随 Mac 1.0.4，不能把 Mac 最新 Swift 功能自动变成 Windows C++ 功能。GitHub 每小时检查两路上游：Windows 源码更新合并、构建验收后发布；Mac 更新同步到 fork，并记录迁移基线，原 Mac 工程仍沿用作者实现。同步冲突或验收失败不会推进稳定更新入口。

本版保留参考项目已知限制。新中文显示只影响绘制，混合模式、裁剪比例和命令注册文本仍保持原内部值。未收录的动态提示会显示参考英文，避免误译用户内容或影响编辑逻辑。
